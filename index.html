Privasi data

Modul ini berada di tampilan admin prototipe. Karena data masih tersimpan di localStorage browser dan belum ada login/server, data pendapatan dan denda belum benar-benar terlindungi dari orang yang membuka website di perangkat yang sama. Jangan gunakan untuk data payroll sensitif sebelum ditambahkan autentikasi admin dan database server.
